# Create an Example Order

Create an example order to plan work for a **Facility**.

## Steps

1. In the main menu, select **Order Management**.
1. Select **New Order**.
1. In **Name**, enter a unique identifier.
1. In **Facility**, select the target **Facility**.
1. Select **Create**.

The order appears in the **Orders** view with the state **Created**.
