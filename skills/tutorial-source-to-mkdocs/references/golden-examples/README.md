# Golden Examples

Exemplary pages that show what "good" looks like for each documentation type. The `tutorial-source-to-mkdocs` skill and the `docs-style-reviewer` agent use these as the standard to imitate — structure, tone, heading style, and asset placement.

> Seed content: replace these with real (sanitized) exemplars from the portals — the best existing tutorial index and procedure page you have. Keep at most one exemplar per page type; annotate *why* it is good with `<!-- why: ... -->` comments.

- `tutorial-index.md` — the landing page of a converted tutorial.
- `procedure-page.md` — a single task/scenario page.
